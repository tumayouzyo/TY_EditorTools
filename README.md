# TY_EditorTools

Unity Editor utilities.
AI slop.

Select Animator Controllers in Project, then right-click → **TY_EditorTools**:

- **Check and Repair Animator**: remove orphan transitions; warn about broken references and empty WD-off states.
- **Fill Empty Motions with proxy_empty**: fill None motions, or report their locations if the clip is unavailable.
